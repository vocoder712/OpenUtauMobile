# Services 与 Helpers 的分工

- `Helpers`：独立的数据处理、计算及适配工具。可以持有计算状态，但不负责全局应用状态、弹窗、平台能力注册或业务流程。
- `Services`：应用编排、平台能力访问和具有应用生命周期的服务。是否包含业务逻辑不是唯一判断条件；日志初始化、剪贴板访问等基础设施也属于服务。
- 接口和结果类型随所属服务放置，避免把 `Helpers` 变成数据类型的杂物目录。

当前分组：

| 位置 | 职责 |
| --- | --- |
| `../Helpers/Audio` | 音频样本分析、帧计数工具 |
| `Dialogs` | 弹窗展示、加载流程和 Toast 通知 |
| `Platform` | 剪贴板、外部链接等平台能力及其契约 |
| `Tracks` | 轨道选择、导入和音色映射流程 |
| `Performance` | 性能采样、指标快照及平台采样契约 |
| 当前目录 | 应用入口能力、服务注册、日志初始化和全局撤销重做 |

新增类型优先使用已有职责分组；不要仅因为某个功能调用它，就将纯计算工具归入 Services。
